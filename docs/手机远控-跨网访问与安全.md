# 手机远控：跨网访问与安全说明

适用：桌面端「远程控制」弹窗里"扫码手机控制"那半边（局域网直连 + 配对 token）。

## 一、前提：手机和电脑要在同一个 Wi-Fi

v1 是局域网直连：服务绑定电脑的所有网卡（0.0.0.0），二维码给出电脑的局域网地址（自动跳过虚拟网卡，如 VMware/WSL/VPN 虚拟适配）。

**扫不出来/打不开的排查顺序：**

1. 手机和电脑是否连的**同一个路由器**（访客网络和主网络通常是隔离的）；
2. 公司/学校 Wi-Fi 常开 **AP 隔离**（设备之间禁止互访）——换手机热点试：电脑连手机的热点，就一定能通；
3. 电脑防火墙是否拦了 Node/Electron 的入站连接（第一次开服务时 Windows 会弹窗，要点"允许"）。

## 二、跨网访问（不在家/不在公司）

v1 不内置云中继（中继意味着流量过第三方服务器）。需要跨网时，用隧道工具把电脑的本地端口转发出去，**二选一**：

### 方案 A：Tailscale（推荐，免费额度够用）

1. 电脑和手机都装 Tailscale（tailscale.com），登同一账号；
2. 电脑端开远控服务（弹窗点"开始"），记下端口（链接里 `:端口` 那一段）；
3. 电脑的 Tailscale IP 在 Tailscale 客户端里看（形如 `100.x.y.z`）；
4. 手机浏览器打开 `http://100.x.y.z:端口/remote.html?token=弹窗链接里的token`。

优点：点对点加密，token 只在你自己的设备网络里传。

### 方案 B：cloudflared（不用装手机 App）

1. 电脑下载 cloudflared（Cloudflare 官网），开远控服务记下端口；
2. 电脑命令行执行：`cloudflared tunnel --url http://localhost:端口`；
3. 终端会给出一个 `https://xxx.trycloudflare.com` 地址；
4. 手机打开 `https://xxx.trycloudflare.com/remote.html?token=弹窗链接里的token`。

注意：这种公共隧道地址 anyone 拿到域名就能碰到服务门口——**token 就是唯一门锁**，别把带 token 的完整链接发给任何人。用完记得在桌面弹窗点"停止"。

## 三、token（配对码）的生命周期

- 每次点"开始"都会**生成全新的 token**，旧链接立即作废；
- 弹窗里的"刷新二维码"= 作废旧 token 换新的（手机掉链后扫新的即可）；
- 点"停止"= 立刻吊销：所有已连手机全部断开，token 失效；
- token 只存在内存里，不落盘、不写日志；
- 手机页鉴权成功后会把 `?token=` 从地址栏抹掉（截图/转发链接不会泄露），浏览器关掉后需要重新扫码。

## 四、安全清单（这扇门到底锁了什么）

| 面 | 现状 |
|---|---|
| 哪些路径要 token | `/ws`（实时通道）和全部 `/api/*`；静态页面本身不含任何工作区数据 |
| token 强度 | 24 字节随机数（约 192 位），猜不出来 |
| 传输加密 | 局域网 v1 是明文 HTTP（同 Wi-Fi 内）；跨网走 Tailscale（自带加密）或 cloudflared（HTTPS） |
| 手机端权限 | 只读对话 + 发消息；Web 通道被永久钉在"终端客户端"角色，**不能**提升为受信主机，凭据配置接口对它显式封禁 |
| 端口 | 每次开启随机挑空闲端口；服务停止端口即关闭 |
| 多设备 | 同时可连多台（弹窗显示在线台数）；刷新二维码会把已连设备全部踢掉 |
| 断线重放 | 手机锁屏回来消息不丢（重放缓冲 8MB），缓冲同样要求已鉴权的通道 |

## 五、桌面弹窗的角标

"已就绪"旁会显示"已连接 N 台设备"（N=当前在线的手机连接数）。看到 N 比你预期的多，就点"停止"重开——所有设备都需要重新扫码。
